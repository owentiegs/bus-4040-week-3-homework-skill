# bus-4040-week-3-homework-skill
Homework 3

- This skill is designed to analyze the tone and message of emails in accordance of the user prompt, then give feedback and suggestions.
- This skills works by first reading the email and determining a desired tone from the user. From this it identifies issues and contradictions in the tone of the email. Finally, the skill responds with feedback, while noting to keep crucial information the same.
- I created this skill because I struggle with ensuring emails to professors and others are professional and academic.
- This skill will be useful when communicating with potential employers and teachers.
